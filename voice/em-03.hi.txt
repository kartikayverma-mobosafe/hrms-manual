Employee code सिस्टम बनाता है, आप टाइप नहीं करते। हर branch को एक short code मिलता है, और टेबल आपको ठीक-ठीक दिखाती है कि वहाँ के code किससे शुरू होंगे और अगला code क्या होगा। बेंगलुरु के कर्मचारी का code बनता है, एम डी एम, डैश, बी एल, डैश, ज़ीरो ज़ीरो ज़ीरो ज़ीरो वन। लोगों को जोड़ने से पहले यह सेट कीजिए, और पूरा होने पर Save Code Format दबाइए। अगर किसी branch का short code नहीं है, तो code चुपचाप पुराने सादे फ़ॉर्मैट पर लौट जाता है।
