Employee codes are built by the system, not typed by you. Each branch gets a short code, and the table shows you exactly what codes there will start with, and what the next code will be. A Bengaluru employee comes out as M.D.M dash B.L dash zero zero zero zero one. Set this up before you add people, and press Save Code Format when you are done. If a branch has no short code, the code quietly falls back to the older plain format.
